## 已完成的里程碑

1. 原厂 4.4 内核与最小 initramfs 验证 TF 挂根和有线网络。
2. 自编 4.4 内核完成原生 Debian 12.15 systemd、SSH 与正常重启。
3. 6.12.115 通过 RAM kexec；定位解压区冲突、timer/DMA 访问异常及熵不足。
4. 7.3.1 通过 RAM 试启动、追加 DTB 的 KRNL 持久启动与配套模块验证。
5. Debian 13.7 升级、正常重启和断电上电验证完成。
6. 临时 RAM 环境只读提取原 Android，服务器校验完成，清理并恢复默认 TF Debian。

历史失败的原因与修复见 [适配经验](bringup-notes.md)。
原始串口与设备回执私有保存；本仓库保留脱敏结论，无法据此承诺任意硬件组合兼容。
